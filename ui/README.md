# Welcome to your 360news app 👋

## Prerequisite

1. npm installed

2. expo go app on your Iphone

3. git

## Get started

1. Clone the repo

   ```bash
   git clone https://github.com/shenhars/360News.git
   cd 360News
   ```

1. Install dependencies

   ```bash
   npm install
   ```

2. Start the app

   ```bash
   npx expo start
   ```

3. Scan the QR code with your phone
